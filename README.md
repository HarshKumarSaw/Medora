# Medora

> A clinic appointment automation concept exploring how voice-based AI can make scheduling faster, clearer, and less dependent on manual front-desk coordination.

## Overview

Medora explores a voice-first workflow for clinic appointment scheduling. The idea is to let patients request appointments conversationally, receive available time slots, confirm a selection, and handle simple rescheduling cases through an AI voice assistant.

The project was built as an exploration of the intersection between **healthcare workflows and technology**.

## What Medora Explores

- ☎️ Voice-based appointment scheduling
- 📅 Finding and confirming suitable appointment slots
- 🔄 Basic rescheduling and unavailable-slot handling
- 🤖 Conversational AI for patient-facing interactions
- 🔗 Connecting a voice assistant with telephony infrastructure
- 🏥 Reducing repetitive scheduling work for clinic staff

## Technology Stack

- **Twilio** — phone and SMS infrastructure
- **Omnidimension** — AI voice-agent layer
- **FastAPI** — backend/API layer
- **OpenAI** — intelligent response generation

## Project Status

**Prototype / technical exploration**

The repository currently focuses on documenting the setup and integration workflow rather than presenting a production-ready clinical system. It is a project exploring how these technologies can be combined for a practical healthcare use case.
